# 著作権侵害可能性評価仕様

## 1. 目的

本仕様は、SansaVRM Studio AI において、AI 前処理または画像生成により得られた画像について、著作権侵害の可能性を評価する仕組みを定義する。

本機能は法的判断を行わない。出力は、著作権侵害の断定ではなく、レビュー要否、類似性リスク、依拠可能性リスク、既存 IP 想起リスク、証拠不足状態を示す評価支援情報とする。

## 2. 適用範囲

対象:

- AI 前処理で生成された多視点画像。
- 分解画像。
- 設定画。
- 画像生成用中間成果物。
- 動画生成へ渡す参照画像。
- 3D 生成前に使用する参照画像。

対象外:

- 法的侵害判定。
- 権利者特定の保証。
- 既存著作物データベース全体との網羅的照合。
- 外部検索サービスの利用を必須とする判定。
- SansaVRM ファイル本体の policy / restriction 反映。

## 3. 前提

- 本段階は SansaVRM へ接続する前の画像・中間素材評価である。
- 制限付き素材や未公開素材を扱う可能性があるため、ローカル処理を原則とする。
- 外部検索、外部 AI、クラウド画像照合は、利用者が明示的に選択した場合のみ使用する。
- 著作権侵害の主要な評価観点として、少なくとも類似性、依拠可能性、既存 IP 想起、証拠不足を扱う。
- 日本法では、侵害成立の議論において類似性と依拠性が重要な論点になり得る。
- 評価結果には、必ず根拠と限界を含める。

## 4. 入力

### 4.1 必須入力

- generated_image_id
- generated_image_path
- generation_context

### 4.2 任意入力

- prompt
- negative_prompt
- seed
- model_name
- source_images
- reference_candidates
- user_notes
- intended_distribution
- target_age_rating

### 4.3 reference_candidates

既存作品、既存キャラクター、既存商品、既存建築物、既存ロゴなど、利用者または別機能が候補として渡した比較対象を表す。

## 5. 出力

### 5.1 評価結果

評価結果は以下を含む。

- result_id
- generated_image_id
- overall_risk
- review_required
- risk_scores
- matched_reasons
- insufficient_evidence
- recommended_actions
- limitations

### 5.2 overall_risk

以下の値を使用する。

- low
- medium
- high
- unknown

### 5.3 risk_scores

以下の評価軸を持つ。

- visual_similarity
- dependency_risk
- existing_ip_association
- prompt_specificity
- source_image_risk
- distribution_risk

## 6. 評価方針

### 6.1 類似性リスク

既存候補との視覚的類似、構図、配色、シルエット、特徴的装飾、ロゴ、キャラクター固有要素などを評価する。

初期 PoC では、ユーザー指定 reference_candidates とメタデータに基づく評価を行う。画像埋め込みや reverse image search は後続拡張とする。

### 6.2 依拠可能性リスク

以下を考慮する。

- prompt に既存作品名、既存キャラクター名、作者名、ブランド名が含まれる。
- source_images に第三者著作物の可能性がある画像が含まれる。
- reference_candidates が明示的に指定されている。
- 生成過程で既存作品への近似を意図した指示がある。

### 6.3 既存 IP 想起リスク

以下を考慮する。

- 作品名、キャラクター名、ブランド名、商標的名称の直接指定。
- 特徴的な服装、色、装飾、武器、シルエットの一致。
- 既存キャラクターの二次創作に見える可能性。

### 6.4 証拠不足

比較対象がない場合、または画像類似評価が未実装の場合、低リスク断定を行わない。

その場合、overall_risk は unknown または medium を許容し、insufficient_evidence に理由を記録する。

## 7. 推奨アクション

評価結果に応じて以下を提案する。

- human_review
- revise_prompt
- reduce_ip_specific_terms
- generate_more_original_variation
- remove_logo_or_symbol
- verify_source_license
- restrict_distribution
- keep_local_only

## 8. 実装方針

### 8.1 最小 PoC

最小 PoC では以下を実装する。

- JSON 入力を受け取る。
- prompt / source_images / reference_candidates / intended_distribution を評価する。
- 評価結果 JSON を出力する。
- 画像そのものの類似判定は未実装として扱う。
- 画像類似判定が未実装であることを limitations に出力する。

### 8.2 後続拡張

後続拡張候補:

- ローカル画像埋め込みによる類似検索。
- ローカル reference library。
- CLIP 系特徴量比較。
- pHash / dHash による近似画像検出。
- ロゴ検出。
- OCR による作品名・ロゴ文字検出。
- ユーザー確認 UI。

## 9. 禁止事項

本機能は以下を行ってはならない。

- 著作権侵害であると断定する。
- 著作権侵害ではないと保証する。
- 権利者の許諾を得たものとして扱う。
- 外部サービスへ画像を無断送信する。
- 証拠不足を低リスクとして扱う。

## 10. トレーサビリティ

本仕様に基づくテスト仕様は、以下の観点を含む。

- 既存 IP 名称を含む prompt の検出。
- reference_candidates 指定時のレビュー要求。
- source_images に license_unknown が含まれる場合の警告。
- 比較対象不足時の unknown または insufficient_evidence。
- 外部送信なしのローカル評価。
