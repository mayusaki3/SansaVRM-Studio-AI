# 要件定義

## 1. 目的

SansaVRM Studio AI の初期要件を定義する。

本要件定義は、SansaVRM を中心とした構造化アセット制作・変換・検証・AI 前処理支援環境を対象とする。

## 2. 対象

本システムは以下を対象とする。

- humanoid character
- non-humanoid character
- animal
- creature
- robot
- mech
- furniture
- building
- prop
- environment asset

## 3. 機能要件

## 3.1 Core 機能

### REQ-CORE-001

SansaVRM Viewer を提供できること。

### REQ-CORE-002

SansaVRM Validator を提供できること。

### REQ-CORE-003

SansaVRM Converter を提供できること。

### REQ-CORE-004

AI 環境が存在しない場合でも、Core 機能が利用可能であること。

### REQ-CORE-005

Windows および Linux で動作可能であること。

### REQ-CORE-006

ブラウザベース UI を提供できること。

### REQ-CORE-007

localhost モードおよび LAN 公開モードを提供できること。

## 3.2 AI 前処理機能

### REQ-AI-001

画像または prompt から多視点画像を生成できること。

### REQ-AI-002

画像を layer 単位へ分解できること。

### REQ-AI-003

対象タイプ別に分解テンプレートを切り替えられること。

### REQ-AI-004

人型以外の asset を扱えること。

### REQ-AI-005

分解結果を downstream generation へ利用できること。

### REQ-AI-006

ローカル AI 実行を原則とすること。

### REQ-AI-007

裸体素体、hidden layer、内部構造推定などを扱えること。

### REQ-AI-008

外部 AI サービスを利用する場合、明示的に選択できること。

## 3.3 policy / restriction / provenance

### REQ-POLICY-001

policy / restriction / provenance 情報を保持できること。

### REQ-POLICY-002

制作状態と流通状態を分離できること。

### REQ-POLICY-003

authoring state と distribution state を区別できること。

### REQ-POLICY-004

export profile を切り替えられること。

### REQ-POLICY-005

成人向け、暴力、グロテスク、裸体状態などを metadata 化できること。

### REQ-POLICY-006

流通制限を metadata 化できること。

### REQ-POLICY-007

改ざん防止ではなく、改ざん検出を重視すること。

## 3.4 著作権侵害可能性評価

### REQ-IP-001

著作権侵害可能性を評価できること。

### REQ-IP-002

法的判定を行わないこと。

### REQ-IP-003

類似性、依拠可能性、既存 IP 想起を評価できること。

### REQ-IP-004

証拠不足を明示できること。

### REQ-IP-005

外部送信なしのローカル評価モードを提供できること。

## 4. 非機能要件

### NFR-001

zip 解凍のみで利用可能な構成を許容すること。

### NFR-002

clone ベースの開発環境を提供できること。

### NFR-003

AI 機能を optional とすること。

### NFR-004

ローカル処理を優先すること。

### NFR-005

未公開素材や制限付き素材を外部送信しない構成を優先すること。

### NFR-006

Viewer / Validator / Marketplace / Exporter との連携を考慮すること。

## 5. 今後の拡張候補

- image embedding
- reverse image search
- CLIP similarity
- OCR
- logo detection
- video generation
- motion generation
- simulation generation
- collaborative editing
- marketplace integration
