# 著作権侵害可能性評価テスト仕様

## 1. 目的

著作権侵害可能性評価仕様に基づき、最小 PoC の評価ロジックが期待通り動作することを確認する。

## 2. テスト方針

- 法的侵害判定は確認しない。
- レビュー要否、risk、insufficient_evidence の出力を確認する。
- 外部サービス未使用前提で確認する。
- 画像類似判定未実装状態を前提とする。

## 3. テストケース

### TC-001

目的:

既存 IP 名称を prompt に含む場合、review_required が true になることを確認する。

入力:

```json
{
  "prompt": "Mario style plumber character",
  "reference_candidates": []
}
```

期待結果:

- review_required = true
- existing_ip_association >= medium
- recommended_actions に revise_prompt を含む

---

### TC-002

目的:

reference_candidates が指定された場合、review_required が true になることを確認する。

入力:

```json
{
  "prompt": "original fantasy mage",
  "reference_candidates": [
    "ExistingCharacterA"
  ]
}
```

期待結果:

- review_required = true
- dependency_risk >= medium

---

### TC-003

目的:

license_unknown な source_image が含まれる場合、verify_source_license が推奨されることを確認する。

入力:

```json
{
  "source_images": [
    {
      "path": "sample.png",
      "license": "unknown"
    }
  ]
}
```

期待結果:

- recommended_actions に verify_source_license を含む
- review_required = true

---

### TC-004

目的:

比較対象不足時、unknown または insufficient_evidence が出力されることを確認する。

入力:

```json
{
  "prompt": "fantasy character"
}
```

期待結果:

- insufficient_evidence != empty
- overall_risk = unknown または medium

---

### TC-005

目的:

画像類似判定未実装状態を limitations に出力することを確認する。

入力:

```json
{
  "prompt": "original sci-fi mech"
}
```

期待結果:

- limitations に image similarity not implemented を含む

---

### TC-006

目的:

ローカル評価モードで外部送信が発生しないことを確認する。

入力:

```json
{
  "local_only": true
}
```

期待結果:

- external_request_count = 0
- local_processing = true

---

## 4. カバレッジ観点

- prompt 評価
- reference_candidates 評価
- source_images 評価
- insufficient_evidence
- recommendation 生成
- local_only mode
- limitation 出力
