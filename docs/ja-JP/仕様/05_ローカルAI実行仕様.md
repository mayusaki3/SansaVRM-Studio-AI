# ローカルAI実行仕様

## 1. 目的

本仕様は、Studio AI のローカル AI 実行構成を定義する。

## 2. 前提

- 制限付き中間素材を扱う可能性があるため、ローカル AI 実行を原則とする。
- AI 機能は optional とする。
- Viewer / Validator / Converter は AI 環境なしでも動作可能とする。
- Windows および Linux を対象とする。
- NVIDIA GPU を優先対象とする。

## 3. AI runtime 構成

## 3.1 orchestration

Studio AI は orchestration layer を持つ。

候補:

- ComfyUI
- custom workflow runtime

## 3.2 vision model

vision / analysis 候補:

- Qwen2.5-VL
- Florence-2

責務:

- asset type estimation
- visible structure detection
- material estimation
- decomposition support
- prompt generation

## 3.3 segmentation

segmentation 候補:

- SAM2
- Grounded-SAM

責務:

- layer segmentation
- object separation
- hidden region support

## 3.4 multi-view generation

候補:

- Zero123++
- Wonder3D
- Era3D
- SyncDreamer

責務:

- front/back/side generation
- hidden area estimation
- downstream 3D support

## 3.5 image generation

候補:

- SDXL
- FLUX

責務:

- refinement
- variation generation
- material variation
- pose generation
- character sheet generation

## 4. local-only mode

local-only mode では以下を保証する。

- 外部 HTTP request を行わない。
- 入力画像を外部送信しない。
- prompt を外部送信しない。
- provenance に local_only=true を保持できる。

## 5. optional external service mode

利用者が明示的に許可した場合のみ、外部 AI サービス利用を許可する。

要求:

- 送信対象表示
- リスク表示
- opt-in
- provider 表示
- provenance 記録

## 6. workflow artifact

workflow artifact 候補:

- prompt pack
- negative prompt pack
- decomposition result
- segmentation mask
- multi-view image set
- provenance metadata
- validation report

## 7. validation

AI runtime validation 候補:

- model availability
- VRAM requirement
- workflow compatibility
- segmentation result validation
- multi-view consistency
- local-only enforcement

## 8. 次アクション

- 最小 PoC runtime を決定する。
- ComfyUI workflow 候補を整理する。
- segmentation PoC を作成する。
- local-only enforcement 方法を整理する。
