# ローカルAI実行テスト仕様

## 1. 目的

ローカルAI実行仕様に基づき、local-only mode と optional external service mode の挙動を確認する。

## 2. テストケース

### TC-LAI-001

目的:

local-only mode で外部 HTTP request が発生しないことを確認する。

入力:

```json
{
  "local_only": true
}
```

期待結果:

- external_request_count = 0

---

### TC-LAI-002

目的:

外部 AI サービス利用時に opt-in が必要であることを確認する。

入力:

```json
{
  "external_service": true
}
```

期待結果:

- opt-in required

---

### TC-LAI-003

目的:

provenance に local_only=true を保持できることを確認する。

入力:

```json
{
  "local_only": true
}
```

期待結果:

- provenance.local_only = true

---

### TC-LAI-004

目的:

workflow artifact が生成されることを確認する。

期待結果:

- prompt pack generated
- segmentation mask generated
- provenance metadata generated

---

### TC-LAI-005

目的:

model availability validation を行えることを確認する。

期待結果:

- missing model detection
- runtime validation error

---

## 3. カバレッジ観点

- local-only enforcement
- opt-in
- provenance
- workflow artifact
- runtime validation
