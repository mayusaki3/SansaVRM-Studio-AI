# 環境設定

## 1. 目的

本ドキュメントは、SansaVRM Studio AI の初期 PoC を実行するための環境設定手順を整理する。

現時点では、AI 実行環境ではなく、project workspace、workflow、artifact registry、local server、minimal validation UI を確認するための環境を対象とする。

## 2. 対象環境

## 2.1 開発用

開発用は Git clone を前提とする。

対象:

- Windows 11
- Linux
- Python 3.11 以降

## 2.2 利用者用

利用者用は将来的に zip 解凍で使用できる形を想定する。

現時点では未整備であり、開発用手順で確認する。

## 3. 必要ソフトウェア

- Git
- Python 3.11 以降
- pip
- Web ブラウザ

## 4. リポジトリ取得

```bash
git clone https://github.com/mayusaki3/SansaVRM-Studio-AI.git
cd SansaVRM-Studio-AI
git checkout develop
```

## 5. Python 環境分離方針

SansaVRM Studio AI では、Python 環境を用途ごとに分離する。

理由:

- Core 環境は軽量・安定・AI なしで動作可能にする必要がある。
- AI 環境は GPU、CUDA、PyTorch、モデル依存が大きく、更新頻度も高い。
- 開発・テスト環境は lint、coverage、test runner などを追加する可能性がある。
- 利用者が AI を使わない場合に巨大な AI 依存を要求しない。

## 5.1 Core 環境

Core 環境は、AI なしで動作する最小環境である。

対象:

- local server
- minimal validation UI
- project workspace
- artifact registry
- workflow engine
- copyright risk assessment PoC
- decomposition schema validation

推奨仮想環境名:

```text
.venv
```

## 5.2 AI 環境

AI 環境は、ローカル AI 実行用の環境である。

対象:

- ComfyUI
- Qwen2.5-VL
- Florence-2
- SAM2
- Grounded-SAM
- Zero123++
- SDXL
- FLUX
- CUDA / PyTorch

推奨:

```text
.venv-ai
```

または、ComfyUI など各 AI 実行基盤側の専用環境を使用する。

## 5.3 開発・テスト環境

開発・テスト環境は、テスト、lint、型チェック、coverage などを行うための環境である。

推奨:

```text
.venv-dev
```

初期段階では、Core 環境に unittest 実行を含めてもよい。

将来的には、Core 環境と開発・テスト環境を分離する。

## 6. Core 用 Python 仮想環境

### 6.1 Windows PowerShell

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
```

### 6.2 Linux

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
```

## 7. Core 依存ライブラリ

現時点の PoC では以下を使用する。

```bash
pip install fastapi uvicorn pydantic
```

## 8. ローカルサーバー起動

```bash
uvicorn src.python.local_server:app --reload
```

起動後、以下へアクセスする。

```text
http://127.0.0.1:8000/
```

## 13. トラブルシュート

### 13.1 `ModuleNotFoundError: No module named 'fastapi'`

Core 依存ライブラリをインストールする。

```bash
pip install fastapi uvicorn pydantic
```

### 13.2 `web/index.html not found`

リポジトリのルートディレクトリで `uvicorn` を実行しているか確認する。

### 13.3 PowerShell で仮想環境を有効化できない

実行ポリシーによりブロックされている可能性がある。

```powershell
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
```

### 13.4 AI 環境の依存関係が Core 環境に混ざった

Core 環境を作り直す。

```bash
rm -rf .venv
python -m venv .venv
```

Windows PowerShell の場合:

```powershell
Remove-Item -Recurse -Force .venv
python -m venv .venv
```

## 14. 次アクション

- requirements-ai.txt は AI 実行方式が固まってから追加する。
- 開発用セットアップ手順を自動化する。
- 利用者用 zip 配布構成を整理する。
- ローカルAI環境設定を別ドキュメント化する。
- LAN 公開設定を別ドキュメント化する。
