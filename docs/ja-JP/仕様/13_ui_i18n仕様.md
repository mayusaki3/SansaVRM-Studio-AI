# UI i18n仕様

## 1. 目的

本仕様は、SansaVRM Studio AI の Web UI 多言語化方針を定義する。

初期 PoC では、日本語と英語を対象とする。

## 2. 前提

- UI はブラウザベースである。
- 初期 UI は minimal validation UI である。
- i18n は UI 表示文字列を対象とする。
- artifact_id、workflow_run_id、step_id などの識別子は翻訳しない。
- API の field name は翻訳しない。

## 3. 対象言語

初期対象:

- ja
- en

既定言語:

- ja

## 4. 翻訳対象

翻訳対象:

- ページタイトル
- セクション見出し
- テーブルヘッダー
- 補助説明
- ボタン
- ステータス表示ラベル

翻訳対象外:

- artifact_id
- workflow_run_id
- step_id
- artifact_type
- workflow_type
- step_type
- API JSON field name
- file path

## 5. 言語選択

UI は言語選択を提供する。

初期 PoC では、ブラウザの localStorage に選択言語を保存する。

保存 key:

```text
svsa_ui_language
```

## 6. 実装方式

初期 PoC では、`web/index.html` 内に最小辞書を持つ。

将来的には以下へ分離する。

```text
web/i18n/ja.json
web/i18n/en.json
```

## 7. 禁止事項

- 識別子を翻訳してはならない。
- API field name を翻訳してはならない。
- 翻訳が存在しない場合に空文字を表示してはならない。
- 翻訳未定義時は key または fallback 言語を表示する。

## 8. 次アクション

- minimal validation UI へ言語セレクタを追加する。
- ja/en の最小辞書を追加する。
- i18n テスト仕様を追加する。
