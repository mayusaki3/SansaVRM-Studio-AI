# 環境設定

## 1. 目的

本ドキュメントは、SansaVRM Studio AI の初期 PoC を実行するための環境設定手順を整理する。

現時点では、AI 実行環境ではなく、project workspace、workflow、artifact registry、local server、minimal validation UI を確認するための環境を対象とする。

## 2. 対象環境

## 2.1 開発用

開発用は Git clone を前提とする。

対象:

- Windows 11
- Linux
- Python 3.11 以降

## 2.2 利用者用

利用者用は将来的に zip 解凍で使用できる形を想定する。

現時点では未整備であり、開発用手順で確認する。

## 3. 必要ソフトウェア

- Git
- Python 3.11 以降
- pip
- Web ブラウザ

## 4. リポジトリ取得

```bash
git clone https://github.com/mayusaki3/SansaVRM-Studio-AI.git
cd SansaVRM-Studio-AI
git checkout develop
```

## 5. Python 仮想環境

### 5.1 Windows PowerShell

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
```

### 5.2 Linux

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
```

## 6. 依存ライブラリ

現時点の PoC では以下を使用する。

```bash
pip install fastapi uvicorn pydantic
```

## 7. ローカルサーバー起動

```bash
uvicorn src.python.local_server:app --reload
```

起動後、以下へアクセスする。

```text
http://127.0.0.1:8000/
```

## 8. API 確認

```text
GET http://127.0.0.1:8000/api/health
GET http://127.0.0.1:8000/api/project
GET http://127.0.0.1:8000/api/artifacts
GET http://127.0.0.1:8000/api/workflow-runs
GET http://127.0.0.1:8000/api/workflow-graph
```

## 9. テスト実行

```bash
python -m unittest discover -s tests/python
```

## 11. LAN 公開

初期状態では localhost 専用とする。

LAN 公開は未整備であり、認証・アクセス制御・制限付き素材の扱いを整理してから有効化する。

## 12. トラブルシュート

### 12.1 `ModuleNotFoundError: No module named 'fastapi'`

依存ライブラリをインストールする。

```bash
pip install fastapi uvicorn pydantic
```

### 12.2 `web/index.html not found`

リポジトリのルートディレクトリで `uvicorn` を実行しているか確認する。

### 12.3 PowerShell で仮想環境を有効化できない

実行ポリシーによりブロックされている可能性がある。

```powershell
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
```
